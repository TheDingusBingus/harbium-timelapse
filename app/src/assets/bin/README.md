Put the Windows programs the app uses here before building (they're never committed):

- exiftool.exe, plus the exiftool_files folder that comes with it (https://exiftool.org, Windows
  Executable, renamed from "exiftool(-k).exe")
- ffmpeg.exe (for example from https://www.gyan.dev/ffmpeg/builds/)

Copy them from experiments/flet-check/src/assets/bin if you already have them there.
